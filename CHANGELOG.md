# Changelog

## Unreleased

- Xpecs is now the one Skale app for looking after a PC: it includes Xcare (overview with health
  score, cleaner, startup programs, apps, optimize, Force Delete) and Xpace (Disk space: search box,
  folder tree with treemap, largest files, file types, Recycle Bin and reviewed permanent deletion).
  The menu groups the pages under PC care, Hardware and Tools; the hardware parts are tabs.
- Drivers page: devices with problems, driver updates from Windows Update installed as
  administrator after a restore point, the graphics driver with a link to its maker's app, every
  installed driver, and a backup of all manufacturer drivers. Drivers never come from other sites.
- Live sensors start when a hardware page is first opened, not with the window.
- `Xpecs.exe --mcp` runs a local MCP server (no window) for Claude Code, Codex and other MCP
  clients: PC status, junk, startup items, apps, power plans, disk space, drivers, Windows Update
  driver updates, system information, sensors and benchmarks; read-only.

## 0.1.1 — 2026-10-27

- Transparent product symbols without navy background tiles or decorative outer rims.
- Build inputs track the ICO/PNG artwork, and every npm build checks embedded Windows icons.
- English documentation now lists the complete five-app Skale Club family.
